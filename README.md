# 세경고등학교 인공지능반도체과 Virtual Lab · 흡광광도법

세경고등학교 인공지능반도체과 1~3학년을 위한 흡광광도법(흡수 분광법) 온라인 실험실입니다. 수행평가로 사용할 수 있습니다.

## 구성
- **첫 화면**: 학생 입장 / 교사 입장이 나뉘어 있습니다.
- **기초 이론**: 초성퀴즈 · 자음 보고 맞추기 · 괄호 넣기 · OX · 짝 맞추기 · 순서 배열 · 계산 챌린지 (초보 / 중급 / 고급)
- **기초 실습**: 실습기구 도감, 피펫·메스플라스크 조작, 분광광도계 구조, 최대 흡수 파장 찾기, 셀의 종류와 선택, 영점 조정·측정
- **화학분석기능사**: KMnO₄ 표준용액 조제 → 미지시료 희석 → 흡광도 측정 → 검량선 작도 → 답안 작성 → 모의 채점

## 수행평가 배점 (100점)
| 영역 | 배점 | 점수 계산 |
|---|---|---|
| 기초 이론 | 20 | 난이도별 최고 정답률 × 배점 (초보 5 · 중급 7 · 고급 8) |
| 기초 실습 | 20 | 실습 미션 7개 중 완료 수 ÷ 7 × 20 |
| 화학분석기능사 | 60 | 모의 실기 채점 점수(100점, 복장·시약 흘림 감점 포함) × 0.6 |

화학분석기능사는 여러 번 응시하면 가장 높은 회차가 반영됩니다.

## 학생
- 접속할 때마다 **학생 입장**을 누르고 학년·반·번호·이름을 새로 적어야 들어갈 수 있습니다.
- 실험실 첫 화면(허브)에서 자기 수행평가 점수를 확인할 수 있습니다.

## 교사
- **교사 입장** → 비밀번호 입력 (처음 비밀번호: `0405`)
- 학생별 수행평가(영역별 점수·총점), 전체 기록, 학년·반·이름 필터
- **학생별 초기화**(각 줄의 [초기화]) · **전체 초기화**("초기화" 입력 확인) · **비밀번호 변경**

## 파일
| 파일 | 설명 |
|---|---|
| `index.html` | 실험실 전체 (이 파일 하나로 동작) |
| `apps-script.gs` | 학생 결과를 모으는 Google Apps Script |

## 모든 학생 결과를 모으는 설정 (처음 한 번)
스프레드시트를 연결하지 않으면 각 컴퓨터(브라우저)에 기록이 저장되고, 교사 화면에서도 **그 컴퓨터에서 활동한 학생**만 보입니다. 학생들이 각자 기기로 접속한다면 아래 설정을 해 주세요.

1. Google 드라이브에서 **새 스프레드시트**를 만듭니다.
2. **확장 프로그램 → Apps Script**를 열고, 기본 코드를 지운 뒤 `apps-script.gs` 내용을 붙여 넣고 저장합니다.
3. **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 실행 사용자: **나** / 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포** → 권한 허용 ("확인되지 않은 앱" 경고가 나오면 고급 → 이동)
4. 표시된 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.
5. `index.html`을 메모장으로 열어 맨 위 `const SHEET_URL = '';` 따옴표 안에 붙여 넣고 저장 → GitHub에 다시 올립니다.

- 학생 기록은 스프레드시트 **「결과」** 시트에 쌓이고, 초기화한 기록은 **「삭제된 기록」** 시트로 옮겨져 되살릴 수 있습니다.
- 비밀번호는 스프레드시트 쪽에 저장되므로 교사 화면에서 바꾸면 모든 기기에 바로 적용됩니다.
- 비밀번호를 잊었다면 Apps Script 편집기에서 `resetTeacherKey` 함수를 선택하고 ▶실행하면 `0405`로 돌아갑니다.
- Apps Script 코드를 바꾼 뒤에는 **배포 → 배포 관리 → 수정 → 새 버전**으로 다시 배포해야 반영됩니다.

> 모의 채점의 문항별 원점수는 수업용으로 정한 값이며, 실제 국가기술자격 배점과 다를 수 있습니다.
